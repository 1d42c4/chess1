# Chess1 — Chess Mastery PDF Library

A compact library of **25 PDFs** covering calculation, positional play, pawn structures, attack and defense, openings, endgames, practical decisions and training. It also includes a ten-PDF White **1.d4/2.c4 repertoire**.

## Start reading

1. Open the [Library Guide](00%20Start%20Here/00_Library_Guide.pdf).
2. Read the [Thinking System](00%20Start%20Here/01_Thinking_System.pdf).
3. Choose a subject folder and work through its PDFs.

For the White repertoire, start with the [course guide and repertoire map](05%20Openings/1.d4%202.c4%20Complete%20Repertoire/00_Course_Guide_and_Repertoire_Map.pdf).

## Changes and protection

The default branch is protected against force pushes and branch deletion. Changes go through a pull request, with no user or app bypass exemptions. Independent review approval is not required, so the owner can maintain the library without another collaborator.

Files can still be edited or deleted through a merged pull request. The owner can change the protection rules or delete the entire repository. Keep a local copy of material you want to retain.

## Use and corrections

Follow the licenses, credits and reuse instructions included with each collection. If you find an error, identify the course, file, page or section, and the move or explanation that needs correction.
